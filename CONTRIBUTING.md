# Contributing

Suggestions and bug reports for navigation, accessibility, text search, lesson explanations, interactive visuals and tests are welcome.

For changes to legal content, supply a clear citation to the exact Act, section, schedule, Rule or notification and its effective date. Never silently edit the original Gazette PDF files or present an illustration as statutory wording. Distinguish source text, commentary and speculative examples. Avoid committing private HR documents or personal information.

For local checks run `npm test` and `npm start`, then verify the app at both narrow phone and desktop widths. This repository does not currently offer an explicit open-source redistribution license; do not assume unrestricted reuse.
